LolMobil Companion
==================

Pilote le client League of Legends depuis ton téléphone : choix du mode,
file d'attente, acceptation des parties, bans/picks, skins (compatible Rose),
runes et sorts.

1. Lance LolMobil-Companion.exe. Il n'ouvre pas de fenêtre : il se place
   dans la zone de notification (à côté de l'horloge, flèche ^). Clic droit
   sur l'icône : QR code d'appairage, acceptation automatique, démarrage
   avec Windows, journal, Quitter. Au premier lancement, la page avec le
   QR code et le code d'appairage s'ouvre dans le navigateur.
   - Windows peut afficher « Windows a protégé votre ordinateur » (programme
     non signé) : « Informations complémentaires » puis « Exécuter quand même ».
   - Le pare-feu Windows demande l'accès réseau : coche « Réseaux privés »
     puis « Autoriser ». Sans ça, le téléphone ne peut pas se connecter.

2. Sur le téléphone (même Wi-Fi que le PC) :
   - Android : installe LolMobil.apk, ouvre l'appli, choisis ton PC dans la
     liste (ou scanne le QR code) et tape le code d'appairage affiché par le
     compagnon.
   - iPhone ou sans l'appli : ouvre dans le navigateur l'adresse affichée par
     le compagnon (http://192.168.x.x:8787) et tape le code d'appairage.

3. Avec Rose (skins non possédés) :
   Le compagnon installe tout seul le plugin LolMobil-Remote dans les plugins
   Pengu Loader de Rose (C:\Program Files\Rose\_internal\Pengu Loader\plugins).
   Rose étant dans « Program Files », Windows demande une fois l'autorisation
   (UAC) : accepte, puis redémarre le client LoL.
   Installation manuelle : copie le dossier LolMobil-Remote de ce zip dans le
   dossier « plugins » de Pengu Loader.

4. Hors de chez toi (pas le même Wi-Fi, 4G) : rien à configurer. Scanne une
   fois le QR code « Accès à distance » de la page d'appairage avec l'appli.
   Les échanges passent par des serveurs MQTT publics gratuits, chiffrés de
   bout en bout. Chez toi, sur le même Wi-Fi que le PC, l'appli passe toute
   seule en connexion directe (plus rapide). Si le pare-feu Windows demande
   l'autorisation pour LolMobil Companion, accepte sur les réseaux privés.
   Pour couper l'accès à distance : LolMobil-Companion.exe -remote off

5. Builds OP.GG / Blitz : dans la sélection des champions, onglet « Builds »,
   choisis un build populaire et touche « Appliquer » : page de runes, set
   d'objets (boutique en jeu) et sorts. Option pour le faire
   automatiquement au verrouillage du champion. Si Blitz est injoignable
   depuis le PC, les builds OP.GG sont utilisés à la place.

Options utiles (dans un terminal) :
  LolMobil-Companion.exe -pair              ouvre la page avec le QR code
  LolMobil-Companion.exe -reset-pairing     nouveau code (déconnecte les téléphones)
  LolMobil-Companion.exe -league-path "D:\Riot Games\League of Legends"
  LolMobil-Companion.exe -pengu-plugins "D:\Pengu Loader\plugins"
  LolMobil-Companion.exe -port 8787

Configuration et journal : %APPDATA%\LolMobil\ (config.json, companion.log)
